01

Executive Summary｜执行摘要

Executive Summary｜执行摘要

【链上可验证】 Base 账户 0x719eae70d4A83f35bF82A2740699F5db84BE919D 在 MAMO/USD feed 于约 22 分钟内从 $0.010597 升至 $0.431274（约 40.7×）期间，以约 14.99M MAMO 作为抵押，从 Moonwell Base Core Markets 成功建立 USDC、WETH、wstETH 与 cbBTC 债务。2M AERO borrow 调用虽显示外层交易 success，但 Compound 函数返回错误码、没有 AERO Transfer。截止区块下，抵押品几乎被清算殆尽，剩余四类债务按当时 oracle 价格合计约 $9.124M；Comptroller 的账户 shortfall 约 $9.124M。

【官方确认】 Moonwell 只确认“MAMO Core Market 出现问题，正在调查”，并把 Base 全部 Core Markets borrow caps、MAMO/WELL supply caps 设为 1 wei。官方尚未确认 exploit、攻击者、根因、损失、补偿或追回。链上 pause flags 仍为 false，准确表述是“cap 封顶，实际上阻止新增借款/指定资产新增供应”，不是市场合约全面暂停。

【链上可验证】 事件账户之后把 8,729,453.826392 USDC 分两笔通过 CCTP burn 发送到 destinationDomain 0。这个数字是跨链退出毛额，不等于 Moonwell 坏账，也不等于净利润；初始 MAMO 的取得成本、操纵成本、交易滑点、清算回收与地址控制关系仍需归集。

决策结论： 现阶段最可靠的风险锚是链上 shortfall 约 $9.124M，而非帖子中的“$6M 净赚”或“$8.7M 被盗”。受影响四市场可见储备合计仅约 $35.9K；若没有追回/注资，储备后经济缺口仍约 $9.088M。风险已经从 MAMO 价格事件转化为共享 Core Market 的跨资产偿付问题。

03

项目背景与策略结构

项目背景与策略

【官方确认】 Moonwell 是 Base 上的 Compound-v2 风格超额抵押借贷协议。每个 mToken 市场独立记账，但 Core Market 通过 Comptroller 共享抵押能力：一个被高估的抵押品可以借走其他市场中的主流资产，因此风险传播方向是 MAMO 价格 → 抵押能力 → 多资产债务 → 各受影响市场的会计缺口。

【官方确认】 MIP-B48 将 MAMO 作为抵押品上线，初始 collateral factor 50%、reserve factor 30%、liquidation incentive 110%、supply cap 20M MAMO、borrow cap 12M MAMO。提案风险分析同时写明，约 $200K MAMO 换成稳定币时滑点可低于 7%。

【机制推断】 关键策略错配不是“有没有价格源”这么简单，而是：薄流动性、可快速重定价的代币 + 50% 抵押因子 + 共享 Core Market + 足够高的供应上限。即使 feed 按设计更新，只要其输入市场可被经济性操纵，协议仍可能把短暂价格当成可借款价值。

04

储备、负债与透明度

Moonwell 市场公开 totalSupply、totalBorrows、reserves 与 cash，但没有一笔“协议总储备”可直接覆盖所有坏账。Compound-v2 风格会计中，无法偿还的账户债务会降低相应 mToken 市场的经济资产价值；最终如何确认、核销、注资或社会化，需要治理动作。

【链上可验证】 截止快照，受影响四类剩余债务约 $9.124M，对应可见市场储备合计约 $35.9K，仅相当于 shortfall 的约 0.39%。21:18:39 的官方 API 快照中，USDC cash 为 0、WETH/ETH cash 约 0.095 ETH；这反映即时退出流动性枯竭，不等于所有存款已经法律上损失。

【官方确认】 截止时官方未披露保险、应急金、DAO treasury 注资、跨市场损失分摊或用户恢复方案；也未披露单一损失数字。

完整影响范围：不要把四个数字混成一个

完整影响范围

  1. 链上账户 shortfall：约 $9.124M。 【链上可验证】 这是 Comptroller 在截止价格下对该账户的抵押不足额，不是协议已核销的 badDebt 计数器。
  2. 受影响市场储备：约 $35.9K。 【链上可验证】 是可见会计缓冲，不等于协议全部 treasury。
  3. 储备后经济缺口：约 $9.088M。 【机制推断】 假设储备可以全额用于同市场吸收，尚未扣除追回/注资。
  4. 跨链退出毛额：8.729M USDC。 【链上可验证】 两笔 CCTP burn 的面值；不是净利润，也不与 shortfall 一一对应。
  5. 最终用户损失：未知。 【官方确认】 取决于追回、冻结、清算回收、DAO/团队/保险注资和会计核销方式。
  6. 法律追偿与资产冻结：未知。 没有公开的执法、Circle 冻结或交易所协作确认。

【媒体报道】 原始帖子称“MAMO 8×、借出 cbBTC/USDC 约 $8.7M、净赚约 $6M”。链上回放支持事件方向，但 feed 峰值相对 17:06 基线约 40.7×，且直接债务资产不止 cbBTC/USDC；“$6M 净赚”缺乏完整成本归集，故不作为本报告定量锚。

敞口与恢复情景

情景以 $9.124M shortfall 为起点，仅做恢复/注资敏感性，不给主观概率：

  • 乐观｜恢复/覆盖 75%–100%｜残余 $0–2.28M：跨链资产冻结/返还，或 DAO、团队、保险与外部资本覆盖大部 shortfall。
  • 基准观察区间｜恢复/覆盖 25%–50%｜残余 $4.56M–6.84M：只有部分追回或注资，余下通过市场级重组/长期回补消化。
  • 严重｜恢复/覆盖 0%–10%｜残余 $8.21M–9.12M：无实质追回且无足额 recap；经济缺口主要留在受影响市场。

【机制推断】 影响最终恢复率的关键变量依次是：跨链资金是否仍可冻结/返还、地址归属是否可识别、协议/DAO 是否愿意 recap、市场会计如何核销、MAMO 清算残值与后续价格、是否存在更多关联账户。Euler 是追回成功的上界案例；Mango 的部分返还是更接近机制但不可直接套用。

历史案例：找机制，不套赔付率

历史案例

  • Mango Markets（2022） — 相似：薄交易代币价格被迅速抬高，经 oracle 放大抵押/仓位价值，再提走主流资产。 差异：Mango 使用永续仓位；本次证据指向借贷抵押品与共享 Core Market。 结果：CFTC 称 oracle 价格约 30 分钟升逾 13×，提走逾 $110M，后仅部分返还。
  • Euler（2023） — 相似：攻击后需要冻结、追踪、谈判与用户恢复计划。 差异：Euler 根因是代码漏洞，不是薄流动性抵押品价格路径。 结果：官方称全部可恢复资金返还；说明追回可以显著改变最终损失，但不能作为本案基准假设。
  • Moonwell cbETH oracle incident — 相似：同一协议内部的 oracle 事件响应、复盘与治理升级路径。 差异：资产、预言机结构、市场状态与损失规模不同。 结果：可用于评估 Moonwell 后续披露质量，不可机械套用赔付率。

【机制推断】 最接近的机制类比是 Mango：薄流动性原生代币的价格进入抵押/仓位估值，再提走更高质量资产。最重要的反例是 Euler：追回可能把经济损失显著改写，但依赖攻击者行为、执法与谈判，不能先验计入资产。

社区情绪与叙事风险

社区情绪

【社区传言】 原始 X 帖回复中出现“insider”“团队/做市相关地址”“oracle 设计失误”等猜测；截至截止时没有可验证的身份映射或官方结论。报告不复述具体指控对象，也不把互动量当事实可信度。

可观察到的三类情绪：一是对低流动性代币进入共享借贷市场的不满；二是对“oracle 是否按设计却仍可操纵”的误解；三是要求立即公布地址、坏账与赔付方案。【机制推断】 若官方长期只说“调查中”而不提供可复算快照，声誉风险可能从单次技术事件扩展到风险治理可信度。

独立思考与判断

独立思考与判断

  1. 这更像风险参数失配，不必先假定合约漏洞。 feed 的快速上升本身是链上事实；“oracle 被黑”尚无证据。若 feed 忠实反映可操纵市场，问题仍然成立。
  2. 真正的传染通道是共享抵押能力。 MAMO 自身市场规模不大，但它成功支持了 cbBTC、USDC、WETH、wstETH 借款；AERO 调用失败。风险上限应按可借资产与 cap 评估，而不是按 MAMO TVL 评估。
  3. 应急 cap 有效阻止新增风险，却晚于主要跨链退出约 71 分钟。 这提示监控阈值不应只看坏账或价格偏离，还应看“薄抵押品供应突增 + oracle 加速 + 多市场 borrow”。
  4. $9.124M 是当前最有用的总风险锚，但仍会变。 债务利息、资产价格与追回都会改变它；应每天用同一区块重新计算。
  5. MIP-B48 已披露流动性约束，但参数没有把可退出深度变成可借额度约束。 【机制推断】 更稳妥的治理应使用动态 cap、隔离市场、TWAP/多源鲁棒性与按可清算深度折扣的 collateral factor。
